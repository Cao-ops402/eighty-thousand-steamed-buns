# Quick start: put your own words on GitHub

Create a private repository and commit one change to it, in about five minutes, using only the browser. When you finish, your own sentence sits in a repository you control.

## Before you start

- A GitHub account with a verified email address. GitHub blocks repository creation from an unverified account; check yours under **Settings**, then **Emails**.
- A desktop browser: Chrome, Edge, Firefox, or Safari.
- Nothing to install. This task never touches the command line.

## Steps

1. **Start a repository.** In the upper-right corner of any GitHub page, click the **+** icon, then choose **New repository**.
2. **Name it.** In the **Repository name** field, type `hello-github`. Use lowercase letters and hyphens; a space turns into a hyphen.
3. **Keep it private.** Under **Visibility**, select **Private**.
4. **Start with a README.** Turn **Add README** on. Older interface versions show this control as **Add a README file**.
5. **Create it.** Click **Create repository**. GitHub opens the new repository with one file in it.
6. **Open the README.** Click **README.md** in the file list.
7. **Edit it.** Click the pencil icon at the upper right of the file view, then replace the placeholder text with one sentence about yourself.
8. **Commit the change.** Click **Commit changes...**, type `Say hello` in the **Commit message** field, then click **Commit changes**.

## Result check

- **Private** appears next to the repository name.
- The file list contains `README.md`, and your sentence renders below it.
- Your commit message `Say hello` appears above the file list.

If all three items are true, the task is complete.

## If a step fails

- **Create repository** is greyed out: the repository name is empty, or the name is already taken by you.
- No pencil icon: you are not signed in. Sign in, then reload the repository page.
- Your sentence disappeared: the edit was never committed. Repeat Steps 7 and 8.
