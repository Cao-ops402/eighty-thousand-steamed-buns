# How to Create a Private Repository with a README
# Prerequisites
A registered GitHub account (github.com).  
You are already signed in to GitHub in your web browser.  
A modern web browser (Chrome, Edge, Firefox, Safari).

# Steps
**1. Open the new repository page.**  
In the upper-right corner of any GitHub page, click the + icon, then select New repository from the dropdown.  
**2. Name your repository.**  
In the Repository name field, enter a name for your project (for example, my-private-project). You may add an optional description.  
**3. Set the visibility to Private.**  
Under "Visibility," select the Private radio button. This means only you (and people you explicitly invite) can see and access the repository.  
**4. Initialize with a README.**  
Check the box that says Add a README file. This creates a default README.md so your repository is not empty.  
**5. Create the repository.**  
Click the green Create repository button at the bottom of the form.

# Result Check
After the page reloads, confirm the following on your repository's main page:  
The repository name appears in the upper-left, matching the name you entered.  
A gray Private label is shown next to the repository name.  
A file named README.md appears in the file list.  
The contents of the README (by default, the repository name as a heading) are rendered directly below the file list on the main page.

If all four items are visible, your private repository with a README has been created successfully.
